# AI Leverage Group

**[aileveragegroup.com](https://aileveragegroup.com)** — We help software companies become AI companies.

## About

AI Leverage Group is a senior advisory practice that embeds with leadership teams navigating the shift to agentic AI. One operator, full accountability, start to finish.

Three focus areas:
- **Talent** — Define the AI hiring bar. Build the org that executes.
- **Operating Model** — Stage-gated rollouts, internal scorecards, decision rhythm.
- **Vendor & Tech** — Cut through the noise, pick the right stack, measure ROI.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## Local Development

```sh
git clone https://github.com/anujarora8/aileverage.git

```
